# 灰色无耳车罩首图｜固定排版母版提示词

## 使用原则

- 此模板锁定文字布局、字体风格、字号层级、Tozaroa Logo位置、尺码卡片位置和底部功能栏结构。
- 后续只替换：车型英文官方名、俄罗斯消费者常用搜索名、车身形式、年份、后台尺码码及必要的辅助版本名。
- 背景允许更换为真实秋冬场景；文字颜色、描边及强调色可以随背景明暗调整，但不得改变布局与层级。
- 车型名称优先采用“官方英文名 + 俄罗斯电商常用俄语称呼”，不能只机械音译，也不能编造俄罗斯市场不存在的叫法。
- Tozaroa Logo必须使用透明底原图，不得增加白色卡片、底板或填充框。

## 可替换字段

| 字段 | 含义 | 示例 |
|---|---|---|
| `{MODEL_LATIN}` | 最大号官方英文车型名 | `LADA PRIORA` |
| `{MODEL_RU_SEARCH}` | 俄罗斯电商常用车型叫法 | `ЛАДА ПРИОРА` |
| `{BODY_RU}` | 俄语车身形式或重要版本 | `СЕДАН` |
| `{YEARS}` | 适配年份 | `2007–2018` |
| `{SIZE_CODE}` | 后台尺码码 | `3M` |
| `{BACKGROUND}` | 真实秋冬背景描述 | `红砖商务园区初雪蓝调夜景` |

## 后续单车型替换规则

1. 从车型数据中确认官方英文名、车身形式、年份和后台码。
2. 补充俄罗斯用户在电商平台常用的车型称呼；通常保留品牌与型号，例如 `LADA PRIORA / ЛАДА ПРИОРА`。
3. 只替换 `{MODEL_LATIN}`、`{MODEL_RU_SEARCH}`、`{BODY_RU}`、`{YEARS}`、`{SIZE_CODE}`。
4. 背景可从“首图背景”目录选择，但必须保持车辆合成区域开阔。
5. 根据背景明暗调整文字颜色、轻微描边和强调色，禁止改变字号、位置和版式结构。
6. 加入车辆及车罩后，单独检查车型轮廓、车罩物理关系、无耳结构、Logo透明背景和俄文准确性。
